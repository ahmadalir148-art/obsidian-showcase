# 📚 Obsidian Bot Templates

Готовые n8n шаблоны для быстрого строительства ботов.

## 🤖 Telegram боты

| Файл | Описание |
|------|----------|
| tg_ai_chatbot.json | AI чат-бот с памятью |
| tg_supabase_memory.json | Бот с долгосрочной памятью в Supabase |
| tg_voice_text_images.json | Бот для текста, голоса и изображений |
| tg_long_memory.json | AI агент с долгосрочной памятью + заметки |

## 💬 WhatsApp боты

| Файл | Описание |
|------|----------|
| wa_chatbot.json | Базовый WhatsApp чат-бот |
| wa_ai_rag.json | WhatsApp бот с RAG (база знаний) |
| wa_respond_ai.json | Автоответы в WhatsApp с AI |

## 🚀 Как использовать

1. Скачай JSON файл
2. В n8n: Settings → Import workflow
3. Подставь свои токены
4. Активируй

Источник: [awesome-n8n-templates](https://github.com/enescingoz/awesome-n8n-templates)
